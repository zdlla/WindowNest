# 窗匣 0.20.1

- 修复最小化窗口的关闭按钮不可用：先恢复准确目标窗口，等待其系统关闭控件可用后，再发送一次关闭请求。
- 单窗口关闭和关闭同一应用全部窗口共用修复；不会关闭新出现的其他窗口。
- 未保存文档仍由原应用确认，不自动丢弃更改；关闭失败时尽可能恢复原最小化状态。
- 只在用户点击后进行短暂、有限的异步检查，不增加常驻轮询。
- 保留 0.20.0 的文件盒内部目录浏览、签名更新和完整开源声明。覆盖更新只替换 App，保留全部本机配置及个人文件。

macOS 14+，Apple Silicon / Intel 通用版。下载 WindowNest-0.20.1-universal.zip 后覆盖应用程序中的窗匣.app，或在设置中检查更新。

当前为 ad-hoc hardened runtime 签名，尚无 Developer ID 公证；macOS 可能要求重新确认权限。更新检查仅获取 GitHub 公开发行信息，不上传文件、目录、索引或设置。
