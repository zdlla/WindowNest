## 窗匣 0.20.0

- 设置新增检查更新、每日自动提醒与“下载并更新”。
- 更新清单验证发布签名，安装包核对 SHA-256；只替换 App，保留本机配置、主题、文件盒绑定、多屏布局和个人文件。
- 文件盒内单击文件夹直接浏览下级，支持返回与路径导航；文件单击预览，右键可重命名、用默认应用编辑。
- 在当前目录新建文件夹，拖入也可直接移到当前目录或子文件夹；浏览位置会保存。
- MIT 主许可、完整第三方许可与源码随发行包提供。

### 下载

macOS 14+，Apple Silicon / Intel 通用版：`WindowNest-0.20.0-universal.zip`。源码：`WindowNest-0.20.0-source.zip`。

解压后将窗匣.app放入应用程序文件夹，覆盖旧 App 即可。设置和文件在 App 外单独保存，不会随替换清空。当前未提供 Developer ID 公证，macOS 可能要求确认来源或重新授予权限；不要关闭系统安全保护。

自动版本检查会联系 GitHub，仅获取公开发行信息，不上传文件、目录、索引或设置，可在设置中关闭。
