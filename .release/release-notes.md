# 窗匣 0.20.4

- 新建菜单固定为 16pt 图标与正常系统菜单行高；文件列表及网格图标尺寸独立保留。
- 文件盒和应用第三页改用 Finder 风格：单击选中，双击文件夹进入下级，快速双击文件使用系统默认应用打开。
- 已选中后慢点名称，或按回车，可直接在原位置重命名；快速双击不会误触发重命名。空格和右键可快速查看。
- 新建菜单支持 TXT、RTF、XML、Word、Excel、PPT、Markdown 和 Python；Office 文件使用已校验的小型本地空白模板。其他格式可从本地文件模板复制新建，原文件保持不变。
- 图标模式改为居中网格和两行名称；列表模式保留紧凑排列，统一图标尺寸、名称基线与轻量悬停/选中效果。
- 保留子文件夹拖入移动、主题、多屏布局、折叠、开机启动及最小化窗口关闭修复。
- 覆盖安装只替换 App，保留本机配置、目录绑定、布局和个人文件。

macOS 14+，Apple Silicon / Intel 通用版。下载 WindowNest-0.20.4-universal.zip 覆盖应用程序中的窗匣.app，或在设置中检查更新。

当前为 ad-hoc hardened runtime 签名，尚无 Developer ID 公证；macOS 可能要求重新确认权限。更新检查只获取 GitHub 公开发行信息，不上传文件、目录、索引或设置。
