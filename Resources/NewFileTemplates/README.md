# Blank file templates

These newly generated, content-free OOXML documents are part of WindowNest's MIT-licensed assets. Word has an empty body, Excel an empty worksheet, and PowerPoint one blank slide. They contain no user content, macros, external relationships, embedded fonts or images.

Generated and schema-validated with OfficeCLI 1.0.163 as a development tool. OfficeCLI executable and its runtime are not distributed or required by WindowNest. Creating a file copies this small local template; it does not run OfficeCLI, Office, scripts, network requests or a resident service.
